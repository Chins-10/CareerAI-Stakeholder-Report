## Overview

This repository contains the stakeholder-ready strategy document I produced for 
CareerAI's V1 relaunch — combining competitive research, user sentiment analysis, 
QA findings, and a 2-month sprint plan into a single visual presentation designed 
for product, engineering, and design teams.

The report was built as an interactive HTML document and is hosted on GitHub Pages.

---

## What this report covers

| Section | Description |
|---|---|
| Core insight | The central market opportunity identified through research |
| Competitive landscape | Feature matrix across 4 competitors |
| User sentiment | Top praise and complaint themes from Reddit and platform reviews |
| SWOT analysis | Jobright AI strengths, weaknesses, opportunities, and threats |
| Market opportunities | 5 specific gaps CareerAI can win on |
| Impact vs effort | Prioritization matrix for all recommendations |
| QA findings | Test results, defect summary, and release recommendation |
| Sprint plan | 2-month roadmap across 4 sprints with MoSCoW priorities |

## Key findings at a glance

**The market gap:**
> No competitor wins on both speed and trustworthiness simultaneously —  
> forming CareerAI's core positioning strategy.

**QA results:**
> 35 test cases executed across 4 browser/device combinations.  
> 74.3% pass rate. 1 P0 release blocker identified before public launch.

**Release recommendation:**
> ⚠️ Go with Conditions — approved once DEF-002 (Interview Prep on Safari),  
> DEF-008 (no resume state), and DEF-010 (empty cover letter validation) are resolved.

**Sprint plan:**
> 28 backlog items across 4 two-week sprints — every item traceable to a  
> research finding, test result, or business goal.

## Design decisions

The report was designed as a visual, stakeholder-ready document rather than 
a text report. Key design choices:

- **Dark hero banner** — core insight visible within 3 seconds of opening
- **Colour-coded feature matrix** — green / amber / red badges for instant scanning
- **Progress bars for QA results** — pass rates by browser visible at a glance
- **Sprint cards** — each sprint has a clear goal, priority level, and item list
- **Impact vs Effort 2×2 grid** — visual prioritization framework

The goal was a document a busy product leader could scan in 60 seconds and 
walk away with the three things that matter — what we found, what we recommend, 
and what ships first.
