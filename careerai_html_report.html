3 SWOT — Jobright AI
Understanding the competitor we are up against
Strengths
  • Real-time alerts with genuine speed advantage
  • Match score visible to all users on free tier
  • Strong brand awareness — recommended by ChatGPT
  • "Ask Orion" LinkedIn networking is unique
  • Manual consent gate builds trust in auto-apply
Weaknesses
  • Stale listings mislabeled as recent
  • AI Agent locked behind waitlist for paying users
  • Autofill inaccurate on custom questions
  • Billing discrepancies and no cancel button
  • No interview preparation feature
Opportunities
  • Fix autofill to retain paying users
  • Deliver AI Agent as promised
  • Add interview prep — uncontested space
  • Expand beyond US market
Threats
  • Simplify winning on autofill quality
  • Hirecarta gaining word-of-mouth traction
  • ChatGPT used as a free resume substitute
  • Growing negative Reddit sentiment
4 Opportunities for CareerAI
Five specific gaps — all grounded in user evidence
01
Own the trust position
No competitor has solved AI hallucination. Guarantee AI never fabricates credentials — make this a visible product promise.
02
Radical billing transparency
Price shown = price charged. Cancel button always visible. Jobright's biggest failure — easiest for us to fix. Already verified in QA.
03
Verified job listings
Show a verified posting date on every listing. Make freshness a visible feature, not a backend assumption.
04
Interview prep as differentiator
No competitor offers this at scale. Built-in AI interview prep tied to specific JDs — entirely uncontested.
05
End-to-end workflow
Most users stitch together 3–4 tools. CareerAI becomes the single platform: discover → tailor → apply → prepare → track.
B2B
Bootcamps & career centers
Platform licensing for institutions. Bulk account creation, student onboarding, and admin progress dashboard.

DEF-002 · P0🚫 Release Blocker
Interview Prep button unresponsive on all Safari browsers
Safari mobile (iOS 26.4.2) + Safari desktop (v18.6)
Complete feature failure on Safari. CareerAI's core differentiator is inaccessible on the dominant US mobile browser.
DEF-008 · P1Tailored Resume
No resume state shows empty screen with no actionable next step
Chrome desktop · Windows 11
Resume selection screen loads with "You don't have any resumes yet." The Tailor My Resume button is disabled and no link or button directs the user to upload a resume — user is stuck.
DEF-010 · P1Cover Letter
Empty cover letter fields allow download without validation
Chrome desktop · Windows 11
System downloads an empty cover letter PDF despite all required fields being empty. No validation error shown — user could share a blank PDF without realising.
